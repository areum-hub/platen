# Platen — 종이와 잉크

밤 램프 아래 타자기로 쓰는 메모. 기능은 평범한 노트지만, 종이 질감·타자 소리·따라오는 램프 불빛으로 **쓰는 경험**에 아날로그 감성을 더했다.

- 운영 사이트: **https://memo.dante-labs.com**
- 파일 하나: `index.html` (빌드 없음, 서버 없음)
- 자판 위치대로 한글이 찍힌다. 한/영 상태를 바꿀 필요가 없다.

## 자동 타이핑 몰입 타이머 (내가 더한 기능)

### 만든 이유

PLATEN은 사용자가 타자를 치지 않아도 글이 저절로 찍히는 앱입니다. 그래서 "얼마나 오래 타이핑했나"를 재는 일반적인 뽀모도로 타이머는 이 앱의 성격과 맞지 않았습니다. 필요한 것은 **자동 타이핑을 몇 분 동안 바라보는 경험**을 붙잡아 주는 장치였습니다.

그래서 시간을 재는 대신, 자동 타이핑과 타이머를 한 몸으로 묶었습니다.

- 타이머를 시작하면 자동 타이핑도 같이 시작됩니다.
- 일시정지하면 타이핑이 멈추고, 다시 시작하면 남은 시간과 타이핑 위치에서 이어집니다.
- 초기화하면 타이머만 처음으로 돌아가고, 이미 찍힌 글은 지우지 않습니다.
- 시간이 다 되면 타이핑을 멈추고 알림음과 탭 제목으로 알려 줍니다.

### 핵심 기능 3가지

**1. 5분·10분 몰입 시간 선택**

하단의 `5분` / `10분` 버튼으로 감상할 시간을 고릅니다. 고른 시간이 곧 화면의 카운트다운 시작값이 되고, 시작을 누르면 그 시간만큼 자동 타이핑이 흘러갑니다. 기본값은 5분입니다.

**2. 시작·일시정지·초기화로 자동 타이핑까지 함께 제어**

버튼 하나로 타이머와 자동 타이핑이 동시에 움직입니다. 잠깐 자리를 비우고 싶으면 일시정지, 처음부터 다시 보고 싶으면 초기화입니다. 초기화는 글을 지우지 않으므로 쓰던 내용은 그대로 남습니다.

**3. 종료 알림과 시간 오차 방지**

시간이 다 되면 알림음이 울리고 탭 제목이 `집중 종료 🎉` 로 바뀝니다. 남은 시간은 매번 다시 계산하지 않고 **끝나는 시각을 기준으로 계산**해서, 탭이 느려지거나 백그라운드에 있어도 시간이 밀리지 않습니다.

### 기존 기능은 그대로입니다

타이핑과 한글 자모 조합, 램프 슬라이더 세 개, 램프 켜고 끄기, 자동 타이핑, 리셋, 타자 소리, 글꼴 선택, 글자 크기, 잉크 효과, 자동 저장·복원, 설정 기억하기, `.txt` 다운로드가 모두 그대로 동작합니다. 타이머는 기존 코드를 고치지 않고 **덧붙이기만** 했습니다.

## 실행 방법 (Windows)

이 프로젝트는 빌드도 설치도 필요 없습니다. 아래 세 가지 중 편한 방법을 쓰세요.

### 방법 1 — 파일을 그냥 두 번 클릭 (가장 간단)

탐색기에서 `index.html` 을 더블클릭하면 기본 브라우저에서 열립니다.
주소창에 `file:///C:/.../platen/index.html` 형태로 표시되면 정상입니다.

> 이 방법은 대부분의 기능이 그대로 동작하지만, 브라우저에 따라 자동 저장(localStorage)이 파일 단위로 제한될 수 있습니다. 저장이 이상하면 방법 2를 쓰세요.

### 방법 2 — 로컬 서버로 열기 (권장)

PowerShell 또는 명령 프롬프트(cmd)를 열고 이 폴더로 이동한 뒤 실행합니다.

```powershell
cd C:\Users\areum\git_ws\platen
python -m http.server 8000
```

그다음 브라우저에서 **http://localhost:8000** 을 엽니다.
서버를 끄려면 그 창에서 `Ctrl + C` 를 누릅니다.

- Python 이 없다면 Microsoft Store 에서 `Python 3` 을 설치하거나, Node.js 가 있다면 `npx serve .` 를 써도 됩니다.
- `python` 명령이 안 되면 `py -m http.server 8000` 을 시도해 보세요.
- Git Bash 를 쓴다면 `python -m http.server 8000` 은 동일하게 동작합니다.

### 방법 3 — Git Bash 에서 바로 열기

```bash
cd /c/Users/areum/git_ws/platen
start index.html
```

### 처음 받는 경우 (clone)

```bash
git clone https://github.com/areum-hub/platen.git
cd platen
```

환경변수 설정은 필요 없습니다. 자세한 내용은 `.env.example` 을 참고하세요.

## Hermes 와 함께한 작업 기록

이 기능은 Hermes(개발용 프로필)와 대화하면서 만들었습니다. 무엇을 요청했고, 무엇이 문제였고, 어떻게 풀었는지 순서대로 적습니다.

### 1. 요청

- "자동 타이핑에 몰입할 수 있는 타이머를 넣고 싶다. 5분·10분 중에 고를 수 있게."
- "기존 기능은 하나도 깨지면 안 된다."
- "내 저장소 `main` 에 반영할 수 있게 준비해 달라."

### 2. 구현

- `index.html` 한 파일 안에서만 작업했습니다. CSS 는 `<style>` 에, 마크업은 하단 안내 줄 위에, 동작은 `<script>` 끝부분에 모았습니다.
- 기존 변수·함수 이름과 겹치지 않도록 `focus*` 접두사를 붙였습니다.
- 자동 타이핑의 기존 함수(`startDemo` / `stopDemo` / `isDemoRunning`)를 **그대로 호출**해서, 타이핑 로직을 새로 만들지 않았습니다.

### 3. 사용자 검증

브라우저에서 직접 눌러 확인한 항목입니다.

| 동작 | 확인한 결과 |
| --- | --- |
| 시작 | 05:00 → 04:59 로 줄고, 자동 타이핑이 시작됨 |
| 일시정지 | 숫자가 멈추고 타이핑도 멈춤. 시계가 노란색이 됨 |
| 다시 시작 | 남은 시간부터 이어지고 타이핑 재개 |
| 초기화 | 05:00 으로 돌아가고 쓰던 글은 그대로 남음 |
| 10분 선택 | 10:00 으로 표시가 바뀜 |
| 시간 종료 | 00:00, 알림음, 탭 제목이 `집중 종료 🎉` 로 바뀜 |
| 기존 기능 | 12개 컨트롤 모두 존재, 콘솔 오류 0건 |

### 4. 오류 해결

작업 중 실제로 만난 문제와 고친 방법입니다.

**(1) 원본 PR 의 `</style>` 중복 — 하단 안내 줄 CSS 가 페이지 글자로 새어 나옴**

원본 브랜치에는 스타일시트 중간에 `</style>` 이 하나 더 들어 있어서, 그 뒤의 `.footer-hint` 규칙이 CSS 가 아니라 본문 텍스트로 취급됐습니다. 추가된 닫는 태그를 지우고 스타일시트 하나로 정리했습니다.

**(2) 기본 5분인데 화면은 10:00 으로 표시**

남은 시간의 초기값이 10분으로 잡혀 있어서, `5분` 이 선택된 상태인데도 10:00 이 보였습니다. 초기값을 "선택된 알약의 시간"으로 계산하도록 바꿔 05:00 과 일치시켰습니다.

**(3) 초기화가 자동 타이핑을 멈추지 못함**

초기화 함수에서 상태를 먼저 `false` 로 바꾼 뒤 "돌고 있었으면 멈춘다"를 검사해서, 조건이 항상 거짓이 됐습니다. 검사용 값을 먼저 따로 저장해 두고 상태를 바꾸도록 순서를 고쳤습니다.

**(4) 타이머 패널이 종이 자리를 너무 많이 차지함**

처음 만든 패널은 세로로 쌓인 카드라서 종이 영역을 115px 나 밀어냈습니다. 앱의 핵심인 종이가 줄어드는 건 안 되므로, 한 줄짜리 가로 바로 바꿔 38px 만 쓰도록 했습니다. (종이 높이 330px → 292px, 창을 480px 로 줄여도 하단 안내 줄이 잘리지 않음)

**(5) 타이머 버튼을 누르면 자동 타이핑이 즉시 멈춤**

타이머 패널이 종이 영역(`paperViewport`) 안에 있어서, 버튼 클릭이 종이 클릭으로 전파되며 `stopDemo()` 가 실행됐습니다. 패널에서 클릭 전파를 막아 해결했습니다.

**(6) 최신 `main` 위에 다시 얹기**

원본 PR #51 은 최신 `main` 보다 오래된 지점에서 갈라져 있었고, 그대로 병합하면 그동안 병합된 기능 7건(자동 저장·복원, 설정 기억, 키보드 버튼, TXT 다운로드, 리셋 버그 수정, 상단 페이드, 자모 조합 수정)이 사라질 상태였습니다. 그래서 최신 `main` 위에 새 브랜치(`feat/areum-focus-timer-v2`)를 만들어 타이머 기능만 다시 얹었습니다. 기존 코드는 삭제하지 않았습니다(추가 260줄, 삭제 0줄).

**(7) 보안 검사**

README·`.gitignore`·`.env.example` 을 손보기 전에 저장소 전체에서 API 키·토큰·비밀번호·개인키·이메일 패턴을 검사했습니다. 추적 중인 파일 9개에서 발견된 비밀값은 없었습니다.


## 이 저장소는 수업용입니다

국민대학교 경영대학원 「AI에이전트실무」 7주차 실습 저장소입니다. 수강생이 이 저장소를 **fork** 하고, 자기 해석으로 **기능 하나**를 더해 **Pull Request** 를 보냅니다. 강사가 검토·병합하면 Actions 가 돌아 운영 사이트가 바뀝니다. 수업이 끝나도 저장소는 열려 있습니다.

### 하는 법 (요약)

1. fork 와 clone — 두 줄은 손으로
   ```bash
   gh repo fork dandacompany/platen --clone
   cd platen
   ```
2. 이 폴더에서 개발용 Hermes 프로필(쌤)을 띄운다
   ```bash
   hermes -p dev
   ```
3. 나머지는 쌤에게 자연어로. 브랜치 → 기능 하나 → 브라우저로 **내가** 확인 → 커밋 → 푸시 → PR
4. PR 제목은 `[01분반] 이름: 기능` 형식. 본문은 템플릿이 열린다

자세한 절차와 프롬프트는 수업 전용관의 7주차 실습 가이드에 있습니다.

### 규칙

- **한 PR 에 기능 하나.** 작게. 큰 아이디어는 PR 두 개로 나눈다.
- `index.html` **한 파일**을 유지한다. 외부 라이브러리·빌드 도구를 넣지 않는다 (Google Fonts 는 예외).
- 기존 기능이 그대로 되어야 한다: 타이핑과 자모 조합, 램프 슬라이더 세 개, 램프 켜고 끄기, 자동 타이핑, 리셋, 타자 소리.
- 토큰·API 키·개인 이메일을 넣지 않는다. PR check 가 걸러내지만 사람이 먼저 본다.
- 병합 여부는 강사가 정한다. 수업 중에는 5~8건만 라이브로 병합하고 나머지는 수업 뒤에 병합한다.

### 기능 메뉴

고르거나, 자기 해석으로 새로 정해도 됩니다. 쌤과 brainstorming 으로 범위를 좁힌 뒤 시작하세요.

| 크기 | 예 |
| --- | --- |
| 작게 (15~30분) | 타자 소리 켜고 끄기 버튼 · 3,000자 제한을 실제로 막기 · 종이 색 고르기 · 램프 색(따뜻함/차가움) · 글꼴 고르기 · 자동 타이핑 문구를 내 글로 · 지금 시각 도장 찍기 버튼 · 커서 깜빡임 |
| 중간 (30~45분) | 새로고침해도 글이 남게 저장(localStorage) · `.txt` 로 내보내기 · 제목 줄 · 노트 여러 개와 목록 · 단어 수와 읽는 시간 · 밝은 종이/어두운 종이 전환 |
| 자기 해석 | 완전히 다른 입력 경험. 단, 기존 타이핑과 램프는 남긴다 |

### 로컬에서 열기

`index.html` 을 브라우저로 열면 됩니다. 서버가 필요하면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

### 내 fork 를 원본 최신으로 맞추기

다른 사람의 PR 이 먼저 병합되면 내 브랜치가 낡습니다. 쌤에게 "upstream 최신으로 맞춰 줘" 라고 하면 아래를 합니다.

```bash
git fetch upstream
git rebase upstream/main
```

충돌이 나면 쌤과 같이 봅니다. 작업 중인 변경이 있으면 `git stash` 로 잠깐 치웠다가 `git stash pop` 으로 되돌립니다. rebase 로 역사가 바뀐 브랜치를 다시 올릴 때는 `git push --force-with-lease origin <내 브랜치>` 입니다 (내 브랜치에만).
